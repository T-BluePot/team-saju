# PRD 기능 요구사항

## 용어

| 용어 | 뜻 |
|---|---|
| 사주(四柱) | 연, 월, 일, 시 네 기둥 |
| 팔자(八字) | 네 기둥 x (천간+지지) = 8글자 |
| 천간 | 갑을병정무기경신임계 (10개) |
| 지지 | 자축인묘진사오미신유술해 (12개) |
| 일간 | 일주의 천간. 사주의 주인공, 곧 나 자신 |
| 오행 | 목 화 토 금 수 |
| 십신 | 일간 기준 다른 글자와의 관계. 비견 겁재 식신 상관 편재 정재 편관 정관 편인 정인 |
| 절기 | 태양 황경 기준 24절기. 월주는 달력 월이 아니라 절기로 바뀐다 |

## 플로우

```
랜딩 -> 개인정보 동의 -> 팀원 입력 -> (1명 이상) 결과 -> 공유
  └ 예시 리포트 보기 -> 결과 (표본 팀) -> 내 팀으로 해보기
                      개인 사주 카드
                      팀 오행 지도
                      페어 케미 매트릭스
                      AI 협업 리포트
```

1명이면 1인 모드로 간다. 막지 않되 팀 전용 화면은 뺀다.

랜딩에서 예시 리포트를 먼저 볼 수 있다. 동의는 안 받는다. 개인정보를 넣는 게 아니라서다.

## F0. 개인정보 동의 (P0)

생시는 개인정보다. 그리고 대리 입력 구조라 제3자 정보를 다루게 된다.
자세한 설계는 `06-privacy.md` 참고.

| ID | 요구사항 | 수용 기준 |
|---|---|---|
| F0.1 | 최초 진입 동의 모달 | 수집 항목, 목적, 보관 위치, 보관 기간, 거부 권리, 만 14세 고지. 동의 전에는 입력 화면 진입 불가 |
| F0.2 | 다크패턴 금지 | 체크박스 기본 해제. 동의 버튼과 거부 버튼 시각적 비중 동일 |
| F0.3 | 동의 버전 관리 | 저장된 version이 현재보다 낮으면 재동의 모달 |
| F0.4 | 팀원별 대리 입력 확인 | "본인 정보" / "본인 동의 받고 대신 입력" 라디오 필수. 미선택 시 저장 비활성 |
| F0.5 | 동의 출처 배지 | 팀원 카드에 본인(회색) 또는 대리(노란색) 표시 |
| F0.6 | 상시 고지 | 입력과 결과 화면 하단에 "이 브라우저에만 저장됩니다" 고정 노출 |
| F0.7 | 전체 삭제 | 설정에 "모든 데이터 삭제" 버튼. 확인 1회 후 동의 기록까지 전부 삭제 |

## F1. 팀원 입력 (P0)

| ID | 요구사항 | 수용 기준 |
|---|---|---|
| F1.1 | 이름, 생년월일 | 이름 1~12자, 날짜 1900-01-01 부터 오늘까지 |
| F1.2 | 태어난 시간 | 0~23시. "모름" 선택 가능, 이 경우 시주 빼고 3주만 분석 |
| F1.3 | 양력 음력 선택 | 음력 고르면 윤달 체크박스 노출 |
| F1.4 | 성별 | **v1은 안 받는다.** 대운을 붙이는 스프린트에 그때 다시 받는다 |
| F1.5 | 팀원 CRUD | 최대 8명. 삭제하면 6초 동안 되돌리기 토스트. 되돌리면 원래 자리로. 추가 성공은 라이브 리전으로 알린다 |
| F1.6 | 저장 안 함 | 입력은 메모리에만 둔다. 새로고침하면 사라진다고 화면에 적는다 |
| F1.7 | 시간 보정 토글 | 진태양시 on/off, 기본 on, 설명 툴팁 |
| F1.8 | 이름 별칭 안내 | 실명 아니어도 된다는 안내를 폼에 노출 |
| F1.9 | 팀 이름 입력 | 선택. 비우면 "우리 팀". 공유 리포트 헤더에 들어간다 |

|---|---|---|
| F3.1 | 팀 오행 합산 | 전원 오행 누적해서 팀 분포 산출 |

| F3.7 | 유형별 카피 | 이름, 한 줄, 강점 2, 사각지대 2, 처방 2, 필요한 사람. 사각지대는 반드시 처방과 한 쌍 |

## F5. 팀 리포트 공유 (P1)

공유되는 건 팀 단위 정보뿐이다. 개인 사주 카드, 이름, 생년월일, 누가 누구와
어떤 조합인지는 공유 뷰에 안 들어간다. 상세는 `07-team-report.md`.

| ID | 요구사항 | 수용 기준 |
|---|---|---|
| F5.1 | 공유 뷰 분리 | 팀 내부 뷰와 공유 뷰를 별도 렌더. 공유 뷰에 개인 식별 정보 0건 |
| F5.2 | 마크다운 복사 | 슬랙 노션에 붙여넣을 텍스트. 이름 없음 |
| F5.3 | 링크 공유 | URL에 SharePayload만 인코딩. 팀 이름, 인원 수, 오행 비율, 균형 점수, 조합 집계 |
| F5.4 | 조합 집계 | 페어 케미를 "상생 3쌍 비슷한 결 2쌍 긴장 1쌍" 숫자로만 노출 |
| F5.5 | 이미지 카드 | 히어로 + 레이더 + 강점 1줄. SNS 슬랙용 1장 |
| F5.6 | 유입 동선 | 공유 뷰 하단에 "우리 팀도 해보기" CTA |
| F5.7 | 공유 시트 | 파일 공유가 되는 기기면 `navigator.share` 로 넘긴다. 안 되면 내려받기 |

## 비기능 (P0)

- 반응형 375px 부터 1440px 까지
- 다크모드 시스템 설정 추종
- 8명 전체 재계산 100ms 미만
- 폼 라벨 연결, 키보드 전용 조작, 대비 4.5:1
- JS 번들 gzip 250KB 미만

## 화면

- 랜딩: 히어로 + 3단계 설명 카드 + 재미 콘텐츠 고지
- 동의 모달: 최초 1회. 수집 항목과 보관 위치 명시, 동의 전 진입 차단
- 입력: 좌측 팀원 리스트, 우측 입력 폼, 하단 고정 CTA + 상시 고지 문구
- 결과: 탭 3개로 개인 / 팀 지도 / 리포트. 개인 탭은 내부 전용
- 공유 뷰: 별도 화면. 팀 유형, 오행 레이더, 강점, 처방, 조합 집계, 유입 CTA

## 우선순위

P0은 F0 F1 F2 F3과 비기능 전체. P1은 F4 F5. P2는 대운 세운, 이미지 카드, 서버 저장, 초대 링크.
