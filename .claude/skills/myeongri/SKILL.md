# 명리 도메인 참조

이 프로젝트에서 쓰는 만큼만 담았다. 더 깊은 건 `docs/03-saju-spec.md` 에 있다.

## 사주 여덟 글자

네 기둥이 있고 기둥마다 천간 하나 지지 하나가 붙는다.

| 기둥 | 뜻 |
|---|---|
| 연주 | 태어난 해. **입춘** 기준으로 바뀐다 |
| 월주 | 태어난 달. 달력이 아니라 **절기** 기준 |
| 일주 | 태어난 날. 천간이 곧 **일간**, 사주의 주인공 |
| 시주 | 태어난 시각. 두 시간 단위 |

지지 안에 천간이 숨어 있다. 본기만 세면 土가 과대평가된다.

가중치는 여기 0.2, 중기 0.3, 정기 1.0. 월지에만 1.5배를 곱한다.

## 오행 관계

```
상생  木 -> 火 -> 土 -> 金 -> 水 -> 木
상극  木 -> 土 -> 水 -> 火 -> 金 -> 木
```

## 십신

일간과 대상 글자의 오행 관계, 그리고 음양이 같은지로 정해진다.

| 오행 관계 | 음양 같음 | 음양 다름 |
|---|---|---|
| 나와 같음 | 비견 | 겁재 |
| 내가 생함 | 식신 | 상관 |
| 내가 극함 | 편재 | 정재 |
| 나를 극함 | 편관 | 정관 |
| 나를 생함 | 편인 | 정인 |

이 프로젝트는 십신을 협업 5축으로 옮긴다.

| 축 | 십신 |
|---|---|
| 추진 | 겁재 편재 편관 |
| 기획 | 상관 편인 |
| 조율 | 정관 |
| 실행 | 비견 식신 |
| 분석 | 정재 정인 |

## 이 프로젝트가 정한 것

유파가 갈리는 지점은 아래처럼 고정했다. 바꾸려면 문서부터 고친다.

| 쟁점 | 채택 |
|---|---|
| 야자시 | 23시 이후는 다음날 일주. `setSect(1)` |
| 진태양시 | 기본 켜짐. 동경 135도와 한국 127.5도 차이로 30분을 뺀다 |
| 서머타임 | 시행 연도면 1시간을 뺀다. 유파와 무관하게 항상 |
| UTC+8:30 시기 | 1912년 이전, 1954년부터 1961년까지는 경도 보정 안 함 |
| 시간 미상 | 시주를 빼고 세 기둥만. 절기 판정은 낮 12시 기준 |
| 강약 | 아군 나누기 아군 더하기 적군. 58 이상 신강, 42 미만 신약 |

## 조심할 것

신강 신약은 원래 통근 투출 합충까지 봐야 한다. 여기서 쓰는 건 정량화 가능한
근사치다. UI에 반드시 "간이 판정"이라고 적는다.
