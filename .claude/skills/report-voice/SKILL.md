# 리포트 톤

## 한 줄 기준

**팀 회식 자리에서 누가 소리 내어 읽어도 웃을 수 있는 문장.**

컨설팅 보고서처럼 무겁지 않고, 점집처럼 단정하지 않는다.
읽은 사람이 "어 우리 그런데" 하고 서로 쳐다보게 만드는 게 목표다.

## 절대 규칙

넘으면 안 되는 선이다. 예외 없다.

1. **미래를 단정하지 않는다**
   - 금지: "~할 것이다", "~하게 된다", "반드시"
   - 사용: "~한 경향", "~하기 쉽다", "~할 수 있다"

2. **사람을 배제하지 않는다**
   - 금지: "부적합", "맞지 않는다", "협업 불가", "리더 자질이 없다"
   - 이런 문장은 채용이나 평가 근거로 쓰일 수 있다

3. **건강 수명 질병 사망을 언급하지 않는다**
   - 은유도 안 된다

4. **금전적 조언을 하지 않는다**

5. **부정적 지적에는 반드시 처방이 붙는다**
   - 문제만 말하고 끝나면 사용자는 기분만 나빠진다
   - 사각지대 하나에 처방 하나가 짝이다

6. **주어진 팩트만 쓴다**
   - 간지, 오행, 십신, 강약. 날짜를 추론하거나 새 간지를 지어내지 않는다

7. 한국어, 존댓말. 팀원 이름을 직접 부른다

## 상극을 다루는 법

상극 조합을 "나쁨"으로 표기하지 않는다.

- 라벨은 `긴장감 있는 조합`
- 반드시 조언이 붙는다
- "견제가 품질을 올릴 수도 있다" 같은 양면을 보여준다

## 처방을 쓰는 법

좋은 처방은 이 세 가지를 만족한다.

- 이번 주에 진짜 할 수 있다
- 누가 뭘 하는지 문장에 있다
- 읽고 나서 뭘 해야 할지 안다

```
나쁨: 소통을 원활히 하세요
나쁨: 우선순위를 명확히 하세요
좋음: 스프린트마다 "이번에 접을 것" 한 줄을 정하고 시작하세요
좋음: 회의에 진행자를 한 명 정하고, 그 사람은 의견을 내지 않게 하세요
```

## 유형 이름을 짓는 법

- 짧고 그림이 그려져야 한다
- 웃기되 팀을 까는 게 아니어야 한다
- "못한다"는 팀을 탓하는 게 아니라 **빈자리를 가리키는** 표현이다

```
좋음: 브레이크 없는 팀 / 마감이 없는 팀 / 차가운 회의실 팀
나쁨: 무능한 팀 / 실패하는 팀 / 답 없는 팀
```

## 상시 고지

리포트 어딘가에 항상 있어야 한다.

- `재미로 보는 콘텐츠입니다`
- `입력한 정보는 이 브라우저에만 있고 아무데도 저장되지 않습니다`

## 마지막 점검

문장을 다 쓰고 나서 이걸 묻는다.

- 이 문장을 당사자 앞에서 읽어줄 수 있나
- 미래를 단정하지 않았나
- 지적했으면 처방을 붙였나
- 사람이 아니라 상황을 말하고 있나
