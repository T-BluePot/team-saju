description: 골든 테스트에 새 케이스를 추가한다
---

골든 테스트 케이스를 추가한다. 인자로 생년월일시와 검증하려는 포인트를 받는다.

절차는 이렇다.

1. `docs/03-saju-spec.md` 8장의 기존 케이스를 읽고 번호를 이어붙인다
2. 새 케이스로 `buildChart` 를 실제로 돌려 결과를 뽑는다
3. **결과를 그대로 믿지 말고** 명세와 대조해서 맞는지 확인한다
   - 입춘 경계면 연주가 맞는 해인지
   - 서머타임 기간이면 보정이 들어갔는지
   - 23시대면 다음날 일주인지
4. 확인이 끝난 값만 `src/lib/saju/__tests__/golden.test.ts` 에 고정한다
5. `docs/03-saju-spec.md` 8장 표에도 같은 케이스를 추가한다
6. `npm test` 로 전체를 다시 돌린다

문서와 테스트 둘 다 갱신하지 않으면 끝난 게 아니다.
